# Online marketplace

The goal is to create an online marketplace where users can:

    Create an account and sign in.
    Add, modify, and delete items.
    Browse and search for items using keywords.
    View user profiles with statistics and items posted by each user.
    Assign one or more attributes to an item, such as its category, condition, and accepted payment methods (e.g., cash or mobile payment).
    Bid on items that are for sale.
